# @six5536/pakf-linux-x64

This package contains the prebuilt `pakf` binary for `linux-x64` (Linux, static musl build). It
is an internal artefact of
[`@six5536/pakf`](https://www.npmjs.com/package/@six5536/pakf), which installs
it automatically as an optional dependency on a matching machine. Don't depend
on it directly. Install `@six5536/pakf` instead.

## Status

**Unstable.** `pakf` is at a 0.x version, and its commands, options and file formats can change in any release.
